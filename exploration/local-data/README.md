# Local exploration data

本目录保存未提交 Git 的公共行情采集、网络/时钟诊断和本地验证产物。

当前 `verification/` 由 2026-08-20 至 2026-08-21 的本地/host-smoke 运行产生，约 457 MB。
这些文件被保留，因为数据比已删除的过渡代码更难重建；它们不得被当作正式长期 benchmark：

- 采样窗口短，部分运行只是协议探针；
- 当时本机时钟和系统 DNS 存在已记录问题；
- 市场范围没有完成正式人工冻结；
- 没有真实下单或账户凭据。

大文件由 `.gitignore` 排除。需要删除或归档前，应先提取 report、时间范围、checksum 和结论。
